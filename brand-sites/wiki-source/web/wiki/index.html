This guide documents Web Preview through W26.28. The game you open may have a different release, and saves do not transfer automatically to World.

Overview

Current documentation baseline: Web Preview branch ai/primalbound-independent-web through W26.28 (merged commit 5467b419, 26 October 2026). The core gameplay was originally audited through W22.3C; later player-facing changes are incorporated below. This guide update does not verify a separate production deployment.

Newer Web Preview features: W23–W26.28 #

Homestead gathering plots — W23.1A–C #

  • In Homestead, review the Bones, Herb and Stone plots. All three share one worker, not three simultaneous streams of production.
  • A paused plot can remember its own gathering site. Use its Assign action to move the shared worker directly to that plot, or View locations to select a site.
  • The active plot's Collect action collects the worker's ready production cycles. Viewing a plot does not transfer the worker or create extra output.
  • Existing gathering rates and the eight-hour offline accumulation cap still apply. Plot cards do not multiply workers or resources.

Gear unlocks, sweeps and contracts — W24.1A–W25.1A #

  • Workshop gear recipes and dungeon gear drops now respect the requirement to clear the relevant campaign stage, rather than merely reach it. Orders queued before the change remain collectable.
  • On an already-cleared campaign stage, 2× stamina sweeps are now available alongside 5× and 10×. Each replay consumes one stamina; check available space before mutant gear sweeps.
  • In the Journal, Claim Ready claims all completed, unclaimed Daily Hunting Contract rewards while skipping uncompleted and previously claimed tasks. Individual claims remain available.
  • Daily contract resets use 00:00 AEST (UTC+10).

Cloud and device saves — W26.1–W26.28 #

  • Account History can download the current confirmed cloud revision and earlier retained cloud revisions as JSON backups. The current Device Save can be downloaded separately. An unsynced device change is not automatically part of a cloud download.
  • When switching from device progress to a different cloud save, review the confirmation first. The existing device save is backed up and kept separate; device and cloud saves are not merged.
  • If cloud access is unavailable, the Account panel can offer a verified local account recovery copy stored in that browser. Review the save before loading it; recovery does not silently overwrite cloud progress.
  • Cloud revision history retains up to 10 recovery points. Ordinary autosaves create a new recovery point at most once every six hours so older recovery points are not displaced by rapid syncs. Explicit restores also preserve the replaced version.
  • Legacy & Saves can download preserved device recovery copies, and—after the required confirmation—remove a downloaded copy from the browser without removing the active campaign.
  • Before importing a JSON save, the game first verifies a backup of the existing device save. If it cannot confirm that backup, the import stops without replacing progress. The Previous save before last replacement panel can recover the device save kept before an import or local account recovery.
  • If a device save is unreadable or unrecognized, stop and follow the recovery prompt. Autosaving/replacement is paused where needed. Download the preserved raw copy if offered before choosing to continue; do not repeatedly import or reset over an unresolved warning.
  • Browser storage write checks and Account warnings also protect guest and disconnected saves. If the browser cannot confirm a write, download a backup where offered rather than assuming the displayed progress is safely saved.
  • These recoveries are Web-only in the current release; do not assume that the Desktop/World build uses the same cloud account or save format.

Additional changes in W26.21–W26.28 #

  • Local account recovery (W26.21): Before loading a saved local account copy, review its Stage, Bones and save time. The current device campaign is verified and retained in Legacy & Saves. If the stored account copy has changed or the browser cannot confirm the replacement, recovery stops without knowingly overwriting newer progress. Cloud progress is not uploaded or replaced by this action.
  • Cloud-restore safety (W26.22–W26.23): Restoring cloud history first verifies a device recovery copy. These copies can be reviewed, downloaded, restored to this device, and—after download and confirmation—removed in Legacy & Saves. While cloud history recovery runs, autosaves and account changes pause; if sync or backup verification fails, the older revision is not applied. A restore preserves the save it displaces.
  • Newer save versions (W26.24): An older game version must not import, overwrite, or restore a campaign created by a newer game. The old client warns and pauses saving; a newer cloud backup can still be downloaded for safekeeping, even when it cannot be loaded. Update the game before trying again. Older versionless saves remain importable.
  • Hatchling Growth bonus (W26.25): Dinosaurs bred in the Hatchery gain +2% Attack at each 10% Growth milestone, up to +20% at 100% Growth. This stacks with inherited genes. Growth, Hatchery and Sanctuary show the resulting benefit; existing hatchlings receive it automatically from saved Growth.
  • Faster opening (W26.26): Workshop and gear tools now load when first opened to reduce the game's initial download. The gameplay, existing gear, craft orders and saves are unchanged.
  • Hybrids and artwork (W26.27): The Genetic Lab now displays the correct in-game hybrid names, including Veilstalker. Hybrid portraits use their component species more consistently across Codex, Sanctuary, battles, equipment, Growth, breeding and Outpost. Void Stalker's Troodon and Frosthowl's Yutyrannus artwork was corrected.
  • Multiple-tab protection (W26.28): If another browser tab saves newer progress, the older tab pauses its own device saving rather than overwriting it. Use Download this tab's progress if you want a copy, then Reload latest save to continue from the newer stored campaign. Imports and local account recovery also stop if the device save changes while you review the confirmation. For best results, play in just one active tab.

Which guide sections are current? #

The detailed campaign, battle, crafting, breeding, set, mutation and progression sections below retain their W22.3C verification baseline. This addendum records the W23–W26.28 Preview player changes; the full handbook has not yet been exhaustively re-audited against every subsequent screen. Use the game's live labels for any remaining difference.

This guide explains the current browser game from first login to endgame. It covers the campaign, companions, growth, talents, equipment, sets, stamina, gathering, crafting, breeding, Sanctuary Missions, dungeons, Titans, mutations, DNA, hybrids, weekly/daily objectives, the Codex, Training Grounds and save/cloud systems.

Primalbound Web changes regularly. If the live game and this guide disagree, the live game UI is authoritative and this guide should be updated.

1. The short version — what should a new player do? #

If you are brand new:

  1. Keep a full active pack of up to three dinosaurs.
  2. Push campaign stages until you start losing.
  3. When stuck, improve your pack in this order:
    • Growth
    • Talents
    • Equipment
    • Equipment levels
    • Mutations
    • Prime
    • Better species / better team synergy
  4. Gather Bones, Herbs and Stone from the Outpost while you are away.
  5. Craft useful equipment and camp upgrades in the Workshop.
  6. Repeat cleared bosses or dungeons for gear.
  7. From Expedition Tier 2 (stage 1,001+), farm Mutant Guardians for full equipment sets and first-clear DNA.
  8. Send reserve dinosaurs on Sanctuary Missions so your inactive collection keeps earning supplies.
  9. Use Training Grounds before spending resources if you want to compare packs against a difficult stage.
  10. Claim your Daily Login Reward, and check Daily Hunting Contracts, Weekly Field Contracts and Journey rewards regularly.

The main progression loop is:

Campaign → Bones/Prime/Shards/Gear → improve dinosaurs → beat harder Guardians → unlock better systems → repeat.

2. Main resources #

Bones #

Your main progression currency.

Used for:

  • recruiting dinosaurs;
  • Growth;
  • equipment upgrades;
  • mutations;
  • crafting;
  • Outpost facility upgrades;
  • breeding;
  • late-game hybrid evolution.

Best sources:

  • campaign battles;
  • cleared-stage sweeps;
  • dungeons;
  • Titans;
  • gathering through Fossil Excavation;
  • Daily/Weekly/Journey rewards;
  • Sanctuary Missions.

Prime Essence #

Used mainly for Prime Awakening.

A dinosaur must reach 75% Growth and costs 10 Prime Essence to awaken Prime.

Sources:

  • campaign encounters;
  • Guardians;
  • dungeons;
  • Titans;
  • Daily/Weekly/Journey rewards.

Mutation Shards #

Used for permanent dinosaur mutations and hybrid evolution.

Sources:

  • Guardian fights;
  • first-clear bonuses;
  • dungeons;
  • Titans;
  • Weekly/Journey rewards.

Important farming note:

  • Manual boss replays award repeat Shards.
  • 2×/5×/10× stamina sweeps do not award repeat Shards. Sweeps are for fast Bones, Prime, gear, wins and mastery.

Herbs #

Used for:

  • breeding;
  • stamina tonics;
  • crafting;
  • Nursery / Workshop / Storehouse upgrades.

Main source: Foraging and Sanctuary Missions.

Stone #

Used heavily for:

  • equipment upgrades;
  • crafting;
  • facility upgrades.

Main source: Quarrying and Sanctuary Missions.

Stamina #

Maximum: 100.

Natural recovery:

  • +1 stamina every 2 minutes.

Used for:

  • 2× / 5× / 10× cleared-stage sweeps;
  • Ancient Dungeons;
  • Titan Hunts.

Recovery:

  • Daily Rest: +35, once per AEST (UTC+10) day.
  • Herb Tonic: +25, costs 8 Herbs + 250 Bones, 30-minute cooldown.
  • Crafted Field Tonics: also +25 and use the same 30-minute tonic cooldown.

Game reset clock #

Timed daily/weekly progression uses a fixed AEST (GMT+10 / UTC+10) clock:

  • daily login rewards reset at 00:00 AEST;
  • Daily Hunting Contracts reset at 00:00 AEST;
  • Daily Camp Rest resets at 00:00 AEST;
  • Titan daily victory lockouts reset at 00:00 AEST;
  • Weekly Field Contracts reset Monday at 00:00 AEST.

This clock does not move for daylight saving.

4. Combat and your active pack #

Your active battle party can contain 1–3 recruited dinosaurs.

A full three-dinosaur pack is generally recommended unless you are deliberately testing something.

Battle flow #

Combat is automatic once started.

You can:

  • run at normal speed;
  • switch to 2×;
  • switch to 4×;
  • pause;
  • allow Auto Journey.

Auto Journey modes #

Cautious #

Moves to the next stage only if your displayed Pack Power exceeds the next enemy's threat.

Continuous #

Keeps fighting the next available stage until your pack loses.

Continuous is faster but can throw your pack into a fight it is not ready for.

5. Pack roles and synergies #

Species have roles such as Tank, Guardian, Support, Striker, Hunter, Ambusher, Defender and Apex.

Current combat can activate multiple pack synergies at once.

Frontline Assault #

Requires:

  • a Tank;
  • plus an attacker role such as Striker, Apex, Ambusher or Hunter.

Effect:

  • +8% pack damage
  • +5% defence

Ancient Bulwark #

Requires:

  • Support, Defender or Guardian;
  • plus Tank or Brawler.

Effect:

  • +12% damage reduction

Pack Hunters #

Requires:

  • at least 2 Carnivores.

Effect:

  • +7% pack damage

Defensive roles also attract more normal enemy attacks and receive some built-in mitigation.

Practical pack advice #

A balanced early pack usually benefits from:

  • one durable frontliner;
  • one high-damage dinosaur;
  • one Support / utility dinosaur.

Three glass-cannon attackers may clear easy stages quickly but can collapse against Guardians.

6. Guardian mechanics #

Every 10th campaign level is a Guardian.

Current Guardian rules include:

  • A Guardian Sweep every fourth round.
  • A warning appears one round before the Sweep.
  • Guardians enter Enraged state at 40% Health or lower.
  • Stuns can prevent some Guardian actions.
  • Higher-tier normal Guardians are deliberately stronger than surrounding normal encounters.
  • Final Guardians are stronger again and pay better rewards.

Use the Training Grounds if you are unsure whether your current pack can handle a Guardian.

7. Mutant Guardians #

Mutant Guardians begin in Expedition Tier 2.

They are not random normal enemies. They occupy specific Guardian checkpoints.

Within each 50-stage biome in Tiers 2–10:

  • biome level 20 is a Mutant Guardian;
  • biome level 40 is a Mutant Guardian;
  • biome level 50 is also a Mutant Guardian in biomes 1, 5, 9, 13 and 17;
  • the final stage 10,000 story Guardian remains its own final encounter.

Example — first biome of Tier 2:

  • stage 1,020 mutant;
  • stage 1,040 mutant;
  • stage 1,050 mutant.

The easiest way to find the exact boss you need is:

Armoury → Set Field Guide → choose a set → Find Boss.

Mutant types #

  • Two-Headed Tyrant — Twin Fang Barrage.
  • Rex–Raptor Chimera — Predator Veil / camouflage.
  • Abyss Splicer — Venom Tide.
  • Ironjaw Abomination — Iron Carapace.
  • Void Stalker — Rift Frenzy.
  • Frosthowl Leviathan — Shattering Howl.

Mutants change behaviour at roughly 70% and 40% Health.

8. Sanctuary and recruiting dinosaurs #

The Sanctuary contains the full current roster: 175 species, including normal prehistoric creatures, expanded groups and six hybrids.

You can filter by:

  • Owned
  • On mission
  • Reserve
  • Active pack
  • Recruitable
  • Hybrids
  • Dinosaurs
  • Fliers
  • Oceans
  • Mammals
  • Deepwilds
  • diet
  • and more.

Normal species become recruitable when you reach their unlock stage. Recruitment costs Bones; rarer and later-unlocking creatures cost more.

Hybrids are not normally recruited from the Sanctuary. They are evolved through the DNA Lab.

9. Active pack and saved packs #

You can have up to 3 active dinosaurs.

You can save up to 5 pack presets.

Saved packs:

  • remember membership;
  • do not move equipment;
  • do not automatically replace your active pack when merely selected in the Armoury;
  • refuse to apply if a required dinosaur is missing;
  • refuse to silently substitute another dinosaur;
  • cannot use a dinosaur currently away on a Sanctuary Mission.

Use presets for different purposes, for example:

  • Campaign pack
  • Guardian pack
  • Tanky dungeon pack
  • Carnivore damage pack
  • Breeding / experimental team

10. Dinosaur Growth #

Growth runs from 1% to 100%.

Each +1% Growth:

  • raises the dinosaur's level by 1;
  • adds normal base stats;
  • costs Bones.

Current +1% cost: current Growth × 110 Bones.

Example:

  • growing from 25% to 26% costs 2,750 Bones;
  • later Growth becomes progressively more expensive.

You can:

  • buy +1%;
  • buy +10%;
  • upgrade all owned dinosaurs;
  • hold the +1% button for repeated upgrades.

Bulk purchases are atomic: if you cannot afford the entire requested purchase, no partial bulk spend occurs.

11. Prime Awakening #

Requirements:

  • dinosaur at 75% Growth or higher;
  • 10 Prime Essence.

Prime gives additional permanent power and is applied per individual dinosaur.

If an old save contains a Prime dinosaur below 75% Growth, the Prime state is preserved but remains dormant until 75%.

12. Talent Trees #

A dinosaur earns 1 Talent Point every 10% Growth.

At 100% Growth, a dinosaur has earned 10 total Talent Points.

Each branch has up to 5 ranks.

Ferocity #

Per rank:

  • +6% Attack

Max rank:

  • +30% Attack

Fortitude #

Per rank:

  • +8% Health

Max rank:

  • +40% Health

Survival Instinct #

Per rank:

  • +3% Attack
  • +3% Health
  • +5 flat healing every fourth round

At Rank 5:

  • +15% Attack
  • +15% Health
  • 25 flat healing every fourth round

Important current behaviour #

Survival Instinct:

  • starts counting from the beginning of combat;
  • does not wait until the dinosaur is hit;
  • triggers on rounds 4, 8, 12, 16...;
  • heals the most injured living pack member, not necessarily the dinosaur that owns the Talent.

The current Rank 5 heal is 25 HP flat, not 25%. At high Health totals this is intentionally documented here because it can look almost invisible on the Health bar.

14. Equipment basics #

Every dinosaur has three equipment slots:

  1. Weapon / Fang
  2. Armour / Hide
  3. Relic

Equipment belongs to individual items. One physical item cannot be equipped on two dinosaurs at once.

Item levels #

Gear starts at Level 1 and can be upgraded to Level 10.

Every additional equipment level adds 18% of that item's base stats.

Upgrade cost from current gear level L:

  • 120 × L Bones
  • 3 × L Stone

Example:

  • Lv 1 → 2: 120 Bones + 3 Stone
  • Lv 5 → 6: 600 Bones + 15 Stone

Inventory capacity #

Base capacity:

  • 120 equipment items

Armoury Storehouse:

  • Tier I: 140
  • Tier II: 160
  • Tier III: 180

Locking gear #

The Lock button protects equipment from Breakdown.

Locked gear can still:

  • be equipped;
  • be upgraded.

Auto Equip #

Auto Equip:

  • finds better free equipment;
  • does not steal items from another dinosaur;
  • refuses improvements that would break an active set bonus.

It is intentionally conservative. Manual fitting may still produce a better specialised build.

15. How to get better weapons, armour and relics #

This is one of the most important progression systems.

Normal campaign enemies #

A normal encounter has a 24% chance to drop equipment.

At later stages, successful drops can roll higher rarity.

Normal Guardians #

Bosses / Guardians always drop gear.

If you simply need a better third dinosaur loadout, farming a cleared Guardian is much more reliable than farming ordinary stages.

Dungeons #

A successful full Dungeon clear guarantees one gear drop.

Dungeon gear is useful for filling weak slots:

  • early dungeon → Common;
  • stage-55 dungeon → Rare;
  • stage-120+ dungeons → Epic.

Mutant Guardians #

This is the best source of equipment sets.

Every Mutant Guardian run drops a targeted set piece from one of its supported sets.

A 2×, 5× or 10× sweep of a cleared Mutant Guardian can therefore produce 2, 5 or 10 set pieces, provided you have enough free inventory slots.

First-clear Mutant artifact #

The first clear of a Tier 2+ Mutant Guardian also grants a one-time Tier artifact:

  • Sovereign Fang;
  • Ancient Carapace;
  • or Primal Relic.

These are separate from the normal targeted set drop.

Boss sources:

  • +15% equipment Health

  • 10% less damage from all enemy attacks

Venomheart #

Boss sources:

  • Abyss Splicer
  • Void Stalker

2-piece:

  • +8% equipment Attack and Health

3-piece:

  • every strike adds venom equal to 12% of Attack

Lifebloom #

Boss sources:

  • Frosthowl Leviathan
  • Rex–Raptor Chimera

2-piece:

  • +12% equipment Health

3-piece:

  • after attacking, heal the most injured living pack member for 2% of the set wearer's maximum Health

Mixing tiers #

Set pieces do not need to come from the same Expedition Tier.

Example:

  • T2 Twinfang Fangs
  • T3 Twinfang Carapace
  • T4 Twinfang Talisman

still counts as a full 3-piece Twinfang set.

However, higher-tier pieces have much better raw stats, so replace weaker old pieces over time.

17. Fast gear-farming strategy #

If one dinosaur has bad gear:

  1. Open Armoury.
  2. Inspect the weak dinosaur.
  3. Use Sort: Power.
  4. Try Auto Equip Selected first.
  5. Upgrade any decent existing item that is likely to remain useful.
  6. If you need ordinary filler gear:
    • farm a cleared Guardian;
    • or clear the best Dungeon you can reliably beat.
  7. If you want a proper set:
    • open Set Field Guide;
    • choose the set;
    • press Find Boss;
    • clear that Mutant Guardian once;
    • then use 2× / 5× / 10× sweeps when you have stamina and inventory space.
  8. Lock good pieces.
  9. Break down unwanted gear for Bones and Stone.

Need Shards as well as gear? #

Do manual Guardian replays rather than only sweeps.

Sweeps give:

  • Bones;
  • Prime;
  • gear;
  • victory/mastery/contract credit.

Manual boss replays additionally pay that boss's repeat Mutation Shards.

19. Stamina sweeps #

Once a stage has been cleared, you can repeat it using:

  • 2× sweep — 2 stamina
  • 2× sweep — 2 stamina
  • 5× sweep — 5 stamina
  • 10× sweep — 10 stamina

Each run gives the stage's normal:

  • Bones;
  • Prime reward;
  • gear roll;
  • victory credit;
  • biome mastery credit;
  • relevant Weekly/Daily progress.

Mutant Guardian sweeps require enough free equipment space for all guaranteed set drops.

Sweeps are excellent for:

  • Bones;
  • Prime;
  • gear;
  • mastery;
  • weekly progress.

They are not the method for farming repeat boss Shards.

21. Titan Hunts #

After clearing a biome's stage 50, its Titan Hunt unlocks.

Titans are separate from Mutant Guardians.

A Titan has 3 power phases.

Rules:

  • costs stamina;
  • Titan cost is now deliberately capped: biomes 1–4 cost 12, 5–8 cost 15, 9–12 cost 18, 13–16 cost 21, and 17–20 cost 24 stamina;
  • one successful Titan victory per biome per AEST (UTC+10) day;
  • failed attempts can be retried if you have stamina;
  • victory gives Bones, Prime and Shards.

Titan Trophy Aura #

Each different biome Titan defeated gives a permanent:

  • +1% Attack aura

Maximum:

  • +15%

That makes Titan Hunting a useful long-term account progression system.

23. Outpost gathering skills #

There are four Outpost skills:

  • Fossil Excavation
  • Foraging
  • Quarrying
  • Crafting

Maximum skill level:

  • 50

Gathering continues while you are away, up to an 8-hour offline cap.

Crafting and gathering can run at the same time.

The Homestead shows separate Bones, Herb and Stone plots. Each remembers its selected gathering site and partial cycle, but one shared worker operates only one plot at a time. Opening a plot previews its current site. You can assign the worker directly from a paused plot card; View locations opens the selector when you want a different unlocked site. Ready cycles can be collected from the active plot card or the existing Collect button; both use the same worker collection action. Switching workers collects completed cycles and preserves unfinished progress. Plot selection does not add production: gathering rates, total output, mastery and the 8-hour offline cap remain unchanged.

37. Saves, cloud accounts and recovery (W26.28) #

Primalbound Web can keep a Device Save in this browser and, where account services are available, a separate Cloud Save. Cloud account login uses a username/password separate from Hollow Valley or Steam accounts. These saves do not merge automatically. Desktop/World has a separate save system and does not automatically share these characters or resources.

Starting or reconnecting a cloud account #

  1. Open Player Account and sign in or create a Web account where available.
  2. Compare the current Device Save with the Cloud Save. If they differ, choose deliberately whether to load the Cloud Save or upload the Device Save.
  3. If prompted before loading cloud progress, review the warning. The current device campaign is retained separately and verified before replacement. Signing out returns you to device progress.
  4. Do not assume your cloud copy contains recent unsynced device changes. The Account status shows whether cloud syncing is connected and whether backup warnings need attention.

Download a save before major changes #

  • Legacy & Saves → Export Save: downloads the current device campaign as JSON.
  • Player Account → Download Device Save: also downloads the current device campaign separately from cloud history.
  • Account History → Download Saved Cloud Backup: downloads the last confirmed cloud revision; unsynced device-only changes are excluded.
  • Account History → Earlier revisions: download an older saved cloud version as JSON without restoring it.

Keep these downloaded JSON files somewhere safe before changing browsers, domains, devices or account saves. Import validates the file before replacing progress. Device-local storage belongs to a particular website address and browser; it does not automatically follow a site move.

Cloud history and rollback #

Cloud history can retain up to 10 previous revisions. Routine synchronization creates a new history recovery point no more often than about once every six hours, helping older restore points survive frequent autosaves. An explicit restore also preserves the save it displaces.

To restore an older cloud revision, open Account History, review the target and confirm. Cloud history restoration waits for the latest device progress and synchronisation checks before proceeding; saves/account changes are paused while it runs. The game verifies a local copy of your existing campaign first. If the copy cannot be confirmed, or a delayed save would conflict, recovery stops rather than replacing progress. Cloud restoring is not the same as simply downloading a backup.

Restore an earlier device campaign #

In Legacy & Saves, use the appropriate recovery panel:

  • Previous Save Before Last Replacement: review, download or restore the valid device save kept before your latest import or local account recovery. The replacement preserves the campaign you are leaving as the newest recovery copy. This action does not upload to or replace the cloud.
  • Cloud Restore Copies: review verified device snapshots kept before a cloud-history rollback; download them or restore one to this device. Restoring a device copy leaves cloud progress unchanged. Remove a saved copy only after downloading it, using the confirmation.
  • Device Recovery Copies: download preserved raw copies if the game encountered unreadable or unrecognised browser save data. Raw copies are for safekeeping and may not be valid imports.

A save import must first verify a copy of the current device save. If that backup fails, importing stops without replacing current progress. Never use Reset or repeated imports to bypass an unresolved storage/recovery warning.

Local account backup while offline #

If the cloud cannot be reached, the Account panel may offer Load Local Account Copy saved in this browser, or Restore an Unsynced Local Backup when signed in. Before applying it, the game shows available details such as Stage, Bones and saved time, confirms the current device campaign has a recovery copy, and checks that the source and device saves did not change during review. This loads progress on the device only; upload to Cloud later only if you choose to.

If the browser warns about saving #

  • A Device Save or Backup warning means the browser could not confirm a write or local recovery copy. Download the current save if offered; do not assume visible progress was safely persisted.
  • For an unreadable save, preserve and download the original raw data before continuing. The game may pause autosaving and cloud replacement until you resolve it.
  • For a save created by a newer version, update the Web game before importing or restoring it. Older clients block incompatible saves and cloud downgrades; an incompatible newer cloud backup may still be downloaded for safekeeping.
  • For a Save Conflict across tabs, the stale tab pauses device writes. Download that tab's progress if needed, then use Reload Latest Save. Avoid playing the same device campaign in multiple active tabs.
  • If a save has moved to another website address, export JSON on the old address and import it on the new address before deliberately uploading it to the correct cloud account.

Cloud, browser recovery and storage services can fail; keeping occasional external JSON backups is still recommended.

39. Recommended progression path #

Very early game — stages 1–50 #

Focus on:

  • keeping 3 active dinosaurs;
  • Growth;
  • first Talents;
  • basic crafted equipment;
  • Fossil Excavation / Foraging / Quarrying;
  • Fangwood Dungeon after Stage 10;
  • recruiting useful early species.

Do not spend all Shards immediately. Permanent mutations are valuable later.

Early-mid game — stages 50–250 #

Focus on:

  • filling all 3 gear slots on each active dinosaur;
  • getting gear to useful levels;
  • unlocking better gathering nodes;
  • starting Breeding;
  • upgrading Storehouse / Workshop / Nursery;
  • clearing stronger Dungeons;
  • working toward 75% Growth and Prime;
  • building alternate saved packs.

Late Tier 1 — stages 250–1,000 #

You should be developing:

  • full Levelled equipment;
  • Growth milestones;
  • Prime dinosaurs;
  • mutations;
  • stronger species;
  • Titans and biome mastery;
  • Workshop skill;
  • hatchlings/genes;
  • Weekly/Journey progress.

Try to enter Tier 2 with a stable three-dinosaur team rather than one overpowered dinosaur carrying two weak companions.

Tier 2 — stage 1,001+ #

This is where the major endgame loop begins.

Priorities:

  • Mutant Guardians;
  • set farming;
  • first-clear DNA;
  • Guardian Reconnaissance Sanctuary Missions;
  • Anomaly Watch Weekly Contract;
  • Tier 2 artifacts;
  • full 3-piece sets;
  • hybrid preparation.

Higher Expedition Tiers #

Continue replacing lower-tier gear with higher-tier versions.

Even if an old set gives the correct 3-piece bonus, later-tier pieces have dramatically larger raw stats.

Use:

  • Titan aura;
  • full Growth;
  • Prime;
  • Talents;
  • Mutations;
  • genes;
  • equipment sets;
  • higher-tier species/hybrids;
  • facilities;
  • skill Mastery;
  • Expedition Ascension.

40. If you are stuck on a stage #

Use this checklist in order.

1. Check active party #

Are all three active slots filled?

2. Check Pack Power #

Compare your Pack Power against enemy threat.

3. Check Growth #

Are your main dinosaurs far behind their current Growth potential?

4. Spend Talent Points #

Unused points provide no benefit.

5. Check equipment slots #

Does every dinosaur have Weapon + Armour + Relic?

6. Upgrade equipment #

Level 1 gear can often be made substantially better cheaply.

7. Use Auto Equip #

Then inspect manually.

8. Check set bonuses #

Do not accidentally break a good 2/3-piece set.

9. Consider mutations #

A good permanent mutation can be a major jump.

10. Awaken Prime #

At 75% Growth if you have Essence.

11. Improve team synergy #

A Tank + attacker or Support + Tank/Brawler can outperform three random high-stat dinosaurs.

12. Farm a better Guardian / Mutant #

Gear is often the bottleneck.

13. Fight Titans #

Unique Titan kills add permanent Attack aura.

14. Use Training Grounds #

Compare packs without spending anything.

41. Common mistakes #

Using only one strong dinosaur #

Pack systems reward having a proper team.

Ignoring reserve dinosaurs #

Reserves can run Sanctuary Missions while your main pack fights.

Farming normal enemies for gear #

Normal enemies only have a 24% gear chance. Cleared Guardians are more reliable.

Expecting sweeps to farm Shards #

Sweeps do not award repeat boss Mutation Shards. Manually replay bosses when Shards are the goal.

Breaking a full equipment set #

Use the comparison warning before replacing a piece.

Salvaging good gear accidentally #

Use gear locks.

Spending every Shard early #

Mutations are permanent and hybrids need Shards later.

Forgetting free Stamina recovery #

Use Daily Rest before paying for a tonic if appropriate.

Leaving gathering capped #

Gathering stops accumulating after 8 hours until collected.

Assuming breeding requires the same species #

Parents only need the same diet. Offspring is one of the two parent species.

Expecting breeding to make hybrids #

It cannot. Hybrids require Mutant DNA and the Genetic Lab.

Sending battle-party dinosaurs on missions #

Sanctuary Missions use reserve companions.

Forgetting Weekly reset #

Weekly rewards must be claimed before Monday 00:00 AEST (UTC+10).

Moving websites without a backup #

Export the JSON first.
