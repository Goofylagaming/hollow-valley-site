W34.0 — Dungeon Practice & Pack Comparisons #

Practise all 30 five-floor Ancient Dungeon routes for free. Choose Training Grounds → Dungeon Runs or use Practice on any dungeon card. Even locked dungeons may be previewed, but rehearsal does not unlock them or bypass real entry requirements.

  1. Choose the route and party: compare your current Frontline / Centre / Rear formation with up to five saved pack presets. Each pack uses its own currently worn gear, Growth, genes, talents, Prime and available live combat bonuses. Missing, duplicate or invalid pack members reject that sample until corrected.
  2. Run 20 comparable samples per pack: each seed begins at floor 1 with full Health and runs the real five-floor encounter rules. Survivors carry Health forward and recover 20% maximum Health after non-final wins; downed companions remain down. The 120-round limit for any fight produces an unresolved sample, not a win.
  3. Read the report: full clears, defeats, unresolved samples, average floors cleared, most common stopping floor, per-floor reach/clear counts, Health before rest and recovered HP show where a team struggled. A first-sample floor replay shows targeting and Guardian warnings. These are deterministic comparisons, not calibrated real-run win probabilities.
  4. Adjust and rerun: moving formation slots or assigning/returning Sanctuary Mission members makes older practice reports stale. You can rehearse away companions without recalling them, but they must return for paid dungeon entry.
  5. Keep real progress intact: practice spends no stamina and awards no Bones, Essence, Shards, gear, XP, DNA, contracts or dungeon completion records. It cannot move gear, resume a real frozen run or collect pending cargo.

Save compatibility: W34.0 keeps existing Web save format 15 and introduces no new save migration. All W33.0 dungeon checkpoints, campaign progression, Device Saves and Cloud History are preserved. Back up your current saves before changing builds; older Web clients must not load format-15 saves. World/Desktop saves and its Training Yard remain separate. W33.0 — Playable Dungeon Expeditions #

Ancient Dungeons are now playable five-floor battle expeditions, not one-click power checks. All 30 routes keep their stage gates and IDs. At W33.0 launch, entry was 5–25 stamina; W34.1 supersedes this with 3–9 for the original six and 9–13 for later routes. Check the current route-card price. Open Ancient Dungeons, choose a route, review your Frontline/Centre/Rear formation, gear, stamina and rewards, and enter. Companions away on Sanctuary Missions cannot join a run.

  1. Enter once: spend the shown stamina cost to lock the exact crew, gear, camp bonuses, ascension, five encounters and reward/gear roll. Changing the normal pack later does not change this run.
  2. Play floors 1–5: use regular turn-based combat, equipment-set effects, support skills and Guardian telegraphs. Floor 3 is an elite sentinel, floor 5 a Guardian; Veilstalker Warrens uses the Veilstalker camouflage finale.
  3. Keep survivors healthy: Health carries between floors. After each non-final victory living companions regain 20% maximum Health, rounded up; downed companions stay down. If you dispatch a saved crew member on a Sanctuary Mission while paused, they must return before continuing.
  4. Pause only between floors: checkpoints resume after loading, but reloading during a battle interrupts the run and only retreat remains. Time passing never completes a floor.
  5. Collect on full clear: collect fixed Bones, Prime Essence, Shards, eligible first-clear Shards and one gear roll. Tier 2–10 routes now award one non-set Legendary from that tier, subject to the campaign stage cleared at entry; Tier 1 retains its existing gear pool. Inventory, duplicate gear or wallet validation failures leave all cargo pending until a safe atomic collection.
  6. Retreat or defeat: consolation Bones equal floor((full Bones reward ÷ 2) × cleared floors ÷ 5); no Essence, Shards, gear or stamina refund.

Web save format 15: W33.0 migrates format-14 campaigns to format 15, saving active five-floor runs, serials and last results. Existing dungeon clears, attempts and best-floor records remain without retroactive rewards; completed cargo may remain pending after loading. Export Device and Cloud recovery saves before upgrading. Never open format-15 saves with an older Web client. World/Desktop files are incompatible. Sources: verified W33.0 notes and tested dungeon run contract.

Cloud and device saves — W26.1–W26.28 #

  • Account History can download the current confirmed cloud revision and earlier retained cloud revisions as JSON backups. The current Device Save can be downloaded separately. An unsynced device change is not automatically part of a cloud download.
  • When switching from device progress to a different cloud save, review the confirmation first. The existing device save is backed up and kept separate; device and cloud saves are not merged.
  • If cloud access is unavailable, the Account panel can offer a verified local account recovery copy stored in that browser. Review the save before loading it; recovery does not silently overwrite cloud progress.
  • Cloud revision history retains up to 10 recovery points. Ordinary autosaves create a new recovery point at most once every six hours so older recovery points are not displaced by rapid syncs. Explicit restores also preserve the replaced version.
  • Legacy & Saves can download preserved device recovery copies, and—after the required confirmation—remove a downloaded copy from the browser without removing the active campaign.
  • Before importing a JSON save, the game first verifies a backup of the existing device save. If it cannot confirm that backup, the import stops without replacing progress. The Previous save before last replacement panel can recover the device save kept before an import or local account recovery.
  • If a device save is unreadable or unrecognized, stop and follow the recovery prompt. Autosaving/replacement is paused where needed. Download the preserved raw copy if offered before choosing to continue; do not repeatedly import or reset over an unresolved warning.
  • Browser storage write checks and Account warnings also protect guest and disconnected saves. If the browser cannot confirm a write, download a backup where offered rather than assuming the displayed progress is safely saved.
  • These recoveries are Web-only in the current release; do not assume that the Desktop/World build uses the same cloud account or save format.

1. The short version — what should a new player do? #

If you are brand new:

  1. Keep a full active pack of up to three dinosaurs.
  2. Push campaign stages until you start losing.
  3. When stuck, improve your pack in this order:
    • Growth
    • Talents
    • Equipment
    • Equipment levels
    • Mutations
    • Prime
    • Better species / better team synergy
  4. Gather Bones, Herbs and Stone from the Outpost while you are away.
  5. Craft useful equipment and camp upgrades in the Workshop.
  6. Repeat cleared bosses or dungeons for gear.
  7. From Expedition Tier 2 (stage 1,001+), farm Mutant Guardians for full equipment sets and first-clear DNA.
  8. Send reserve dinosaurs on Sanctuary Missions so your inactive collection keeps earning supplies.
  9. Use Training Grounds before spending resources if you want to compare packs against a difficult stage.
  10. Claim your Daily Login Reward, and check Daily Hunting Contracts, Weekly Field Contracts and Journey rewards regularly.

The main progression loop is:

Campaign → Bones/Prime/Shards/Gear → improve dinosaurs → beat harder Guardians → unlock better systems → repeat.

4. Combat and your active pack #

Your active battle party can contain 1–3 recruited dinosaurs.

A full three-dinosaur pack is generally recommended unless you are deliberately testing something.

Battle flow #

Combat is automatic once started.

You can:

  • run at normal speed;
  • switch to 2×;
  • switch to 4×;
  • pause;
  • allow Auto Journey.

Auto Journey modes #

Cautious #

Moves to the next stage only if your displayed Pack Power exceeds the next enemy's threat.

Continuous #

Keeps fighting the next available stage until your pack loses.

6. Guardian mechanics #

Every 10th campaign level is a Guardian.

Current Guardian rules include:

  • A Guardian Sweep every fourth round.
  • A warning appears one round before the Sweep.
  • Guardians enter Enraged state at 40% Health or lower.
  • Stuns can prevent some Guardian actions.
  • Higher-tier normal Guardians are deliberately stronger than surrounding normal encounters.
  • Final Guardians are stronger again and pay better rewards.

Use the Training Grounds if you are unsure whether your current pack can handle a Guardian.

Every dinosaur has three equipment slots:

  2. Armour / Hide

Equipment belongs to individual items. One physical item cannot be equipped on two dinosaurs at once.

  • 120 × L Bones
  • 3 × L Stone

  • be upgraded.

  • finds better free equipment;
  • does not steal items from another dinosaur;
  • refuses improvements that would break an active set bonus.

It is intentionally conservative. Manual fitting may still produce a better specialised build.

15. How to get better weapons, armour and relics #

This is one of the most important progression systems.

Normal campaign enemies #

A normal encounter has a 24% chance to drop equipment.

At later stages, successful drops can roll higher rarity.

Normal Guardians #

Bosses / Guardians always drop gear.

If you simply need a better third dinosaur loadout, farming a cleared Guardian is much more reliable than farming ordinary stages.

Dungeons #

A successful full Dungeon clear guarantees one gear drop.

Dungeon gear is useful for filling weak slots:

  • early dungeon → Common;
  • stage-55 dungeon → Rare;
  • stage-120+ dungeons → Epic.

Mutant Guardians #

This is the best source of equipment sets.

Every Mutant Guardian run drops a targeted set piece from one of its supported sets.

A 2×, 5× or 10× sweep of a cleared Mutant Guardian can therefore produce 2, 5 or 10 set pieces, provided you have enough free inventory slots.

First-clear Mutant artifact #

The first clear of a Tier 2+ Mutant Guardian also grants a one-time Tier artifact:

  • Sovereign Fang;
  • Ancient Carapace;
  • or Primal Relic.

These are separate from the normal targeted set drop.

17. Fast gear-farming strategy #

If one dinosaur has bad gear:

  1. Open Armoury.
  2. Inspect the weak dinosaur.
  3. Use Sort: Power.
  4. Try Auto Equip Selected first.
  5. Upgrade any decent existing item that is likely to remain useful.
  6. If you need ordinary filler gear:
    • farm a cleared Guardian;
    • or clear the best Dungeon you can reliably beat.
  7. If you want a proper set:
    • open Set Field Guide;
    • choose the set;
    • press Find Boss;
    • clear that Mutant Guardian once;
    • then use 2× / 5× / 10× sweeps when you have stamina and inventory space.
  8. Lock good pieces.
  9. Break down unwanted gear for Bones and Stone.

20. Ancient Dungeons #

W33.0 introduced five-floor playable battles, W34.0 added free rehearsals, and W34.1 halved paid entry costs across all 30 routes. The six original routes (Fangwood Depths, Sunken Catacombs, Obsidian Trials, Crystal Labyrinth, Stormscar Gauntlet, Eternal Prime Trial) now cost 3, 4, 5, 6, 8 and 9 stamina respectively.   1. Open Ancient Dungeons, choose a route and review a Frontline/Centre/Rear party. Companions on Sanctuary Missions must return before entry.
  2. Enter once to spend stamina and freeze the crew, equipment, bonuses, five floors and rewards; changing the outside pack cannot rewrite the run.
  3. Start each fight in the normal combat engine with Guardian warnings, set effects and role synergies. Floor 3 is an elite, floor 5 a Guardian. Survivors recover 20% maximum Health after each non-final win; dead crew remain down.
  4. Pause and resume between floors. A browser reload mid-fight interrupts the run and allows retreat only; a crew member sent away must return before the next floor.
  5. A full-clear claim gives Bones, Prime Essence, Shards, once-only first-clear Shards and gear. Tier 2–10 routes guarantee a non-set Legendary from their tier, limited to your already-cleared stage. If any collection check fails, all cargo remains pending.
  6. Defeat or retreat gives only floor((full Bones ÷ 2) × cleared floors ÷ 5) Bones, with no other loot or stamina refund.

Save and recovery: W33.0 Web save 14 → 15 preserves prior clears, attempts and best floors without retroactive rewards. Run checkpoints and finished cargo persist, and older Web builds must not load this save. World/Desktop uses a separate format. See the full W33.0 guide and Web patch notes.

36. Training Grounds #

W34.0 separates free practice into Campaign & Prime Trials and Dungeon Runs. Simulations spend no stamina and give no rewards, XP, DNA, campaign progression, contracts, dungeon records or equipment changes. Real paid dungeon checkpoints and cargo remain untouched.

Campaign & Prime Trials

Run 20 deterministic samples against campaign stages 1–10,000, Guardians, Mutants or optional Prime Trials. Compare the current pack and saved formations using wins/losses, damage, received damage, healing, survivor Health, average winning rounds and the first sample's replay. Prime Trial rehearsal grants no ranked rewards or Mastery unlocks.

Dungeon Runs — W34.0

  1. Open Training Grounds → Dungeon Runs or select Practice on one of the 30 Ancient Dungeon cards. Locked routes are previews only; their real gates still apply.
  2. Compare the current ordered formation and up to five saved presets, each using its currently equipped gear, Growth, genes, talents, Prime and global bonuses.
  3. Run 20 deterministic five-floor samples per pack with full Health at the start of each sample. Living companions carry remaining Health and recover 20% max between non-final floors, but downed companions do not recover. Reaching the 120-round cap stops that attempt unresolved.
  4. Inspect full clears, defeats, unresolved results, average floors, most frequent stopping floor, floor reach and clear counts, Health before recovery and restored HP, plus the first sample's floor-by-floor replay and Guardian warnings. Sample full-clears are not calibrated win odds.
  5. Rerun after changes to your pack's formation or Sanctuary Mission assignments; the previous report is invalidated. Away companions may be rehearsed, but must return before a real dungeon entry. This cannot advance, resume or replace a paid run.

W34.0 remains Web save format 15. No new migration or permanent practice data is created. Keep Web/World mechanics and saves separate, and export Device and confirmed Cloud backups before changing game versions.

37. Saves, cloud accounts and recovery (W34.1) #

Primalbound Web can keep a Device Save in this browser and, where account services are available, a separate Cloud Save. Cloud account login uses a username/password separate from Hollow Valley or Steam accounts. These saves do not merge automatically. Desktop/World has a separate save system and does not automatically share these characters or resources.

Protected W27–W34.1 format migrations #

Web saves migrate through 8 → 9 → 10 → 11 → 12 → 13 → 14 → 15. W27.1–W31 introduced formats 8–13; W31.1/W31.2 retained 13; W32.0 added Challenge Expeditions in 14; W33.0 adds persistent five-floor dungeon checkpoints, run serials and results in format 15; W34.0 Dungeon Practice keeps format 15 with disposable simulation state; W34.1 changes dungeon entry stamina only and still retains format 15, current checkpoints, pending cargo and earned clears. Earlier clears, attempts and best floors are preserved without retroactive rewards. Reloading during a fight permits retreat only; finished cargo remains pending if safe collection fails. Never downgrade a format-15 Web save: export Device and Cloud revisions and follow stale-tab warnings. World/Desktop local profiles use a separate save format.

Starting or reconnecting a cloud account #

  1. Open Player Account and sign in or create a Web account where available.
  2. Compare the current Device Save with the Cloud Save. If they differ, choose deliberately whether to load the Cloud Save or upload the Device Save.
  3. If prompted before loading cloud progress, review the warning. The current device campaign is retained separately and verified before replacement. Signing out returns you to device progress.
  4. Do not assume your cloud copy contains recent unsynced device changes. The Account status shows whether cloud syncing is connected and whether backup warnings need attention.

Download a save before major changes #

  • Legacy & Saves → Export Save: downloads the current device campaign as JSON.
  • Player Account → Download Device Save: also downloads the current device campaign separately from cloud history.
  • Account History → Download Saved Cloud Backup: downloads the last confirmed cloud revision; unsynced device-only changes are excluded.
  • Account History → Earlier revisions: download an older saved cloud version as JSON without restoring it.

Keep these downloaded JSON files somewhere safe before changing browsers, domains, devices or account saves. Import validates the file before replacing progress. Device-local storage belongs to a particular website address and browser; it does not automatically follow a site move.

Cloud history and rollback #

Cloud history can retain up to 10 previous revisions. Routine synchronization creates a new history recovery point no more often than about once every six hours, helping older restore points survive frequent autosaves. An explicit restore also preserves the save it displaces.

To restore an older cloud revision, open Account History, review the target and confirm. Cloud history restoration waits for the latest device progress and synchronisation checks before proceeding; saves/account changes are paused while it runs. The game verifies a local copy of your existing campaign first. If the copy cannot be confirmed, or a delayed save would conflict, recovery stops rather than replacing progress. Cloud restoring is not the same as simply downloading a backup.

Restore an earlier device campaign #

In Legacy & Saves, use the appropriate recovery panel:

  • Previous Save Before Last Replacement: review, download or restore the valid device save kept before your latest import or local account recovery. The replacement preserves the campaign you are leaving as the newest recovery copy. This action does not upload to or replace the cloud.
  • Cloud Restore Copies: review verified device snapshots kept before a cloud-history rollback; download them or restore one to this device. Restoring a device copy leaves cloud progress unchanged. Remove a saved copy only after downloading it, using the confirmation.
  • Device Recovery Copies: download preserved raw copies if the game encountered unreadable or unrecognised browser save data. Raw copies are for safekeeping and may not be valid imports.

A save import must first verify a copy of the current device save. If that backup fails, importing stops without replacing current progress. Never use Reset or repeated imports to bypass an unresolved storage/recovery warning.

Local account backup while offline #

If the cloud cannot be reached, the Account panel may offer Load Local Account Copy saved in this browser, or Restore an Unsynced Local Backup when signed in. Before applying it, the game shows available details such as Stage, Bones and saved time, confirms the current device campaign has a recovery copy, and checks that the source and device saves did not change during review. This loads progress on the device only; upload to Cloud later only if you choose to.

If the browser warns about saving #

  • A Device Save or Backup warning means the browser could not confirm a write or local recovery copy. Download the current save if offered; do not assume visible progress was safely persisted.
  • For an unreadable save, preserve and download the original raw data before continuing. The game may pause autosaving and cloud replacement until you resolve it.
  • For a save created by a newer version, update the Web game before importing or restoring it. Older clients block incompatible saves and cloud downgrades; an incompatible newer cloud backup may still be downloaded for safekeeping.
  • For a Save Conflict across tabs, the stale tab pauses device writes. Download that tab's progress if needed, then use Reload Latest Save. Avoid playing the same device campaign in multiple active tabs.
  • If a save has moved to another website address, export JSON on the old address and import it on the new address before deliberately uploading it to the correct cloud account.

Cloud, browser recovery and storage services can fail; keeping occasional external JSON backups is still recommended.

39. Recommended progression path #

Very early game — stages 1–50 #

Focus on:

  • keeping 3 active dinosaurs;
  • Growth;
  • first Talents;
  • basic crafted equipment;
  • Fossil Excavation / Foraging / Quarrying;
  • Fangwood Dungeon after Stage 10;
  • recruiting useful early species.

Do not spend all Shards immediately. Permanent mutations are valuable later.

Early-mid game — stages 50–250 #

Focus on:

  • filling all 3 gear slots on each active dinosaur;
  • getting gear to useful levels;
  • unlocking better gathering nodes;
  • starting Breeding;
  • upgrading Storehouse / Workshop / Nursery;
  • clearing stronger Dungeons;
  • working toward 75% Growth and Prime;
  • building alternate saved packs.

Late Tier 1 — stages 250–1,000 #

You should be developing:

  • full Levelled equipment;
  • Growth milestones;
  • Prime dinosaurs;
  • mutations;
  • stronger species;
  • Titans and biome mastery;
  • Workshop skill;
  • hatchlings/genes;
  • Weekly/Journey progress.

Try to enter Tier 2 with a stable three-dinosaur team rather than one overpowered dinosaur carrying two weak companions.

Tier 2 — stage 1,001+ #

This is where the major endgame loop begins.

Priorities:

  • Mutant Guardians;
  • set farming;
  • first-clear DNA;
  • Guardian Reconnaissance Sanctuary Missions;
  • Anomaly Watch Weekly Contract;
  • Tier 2 artifacts;
  • full 3-piece sets;
  • hybrid preparation.

Higher Expedition Tiers #

Continue replacing lower-tier gear with higher-tier versions.

Even if an old set gives the correct 3-piece bonus, later-tier pieces have dramatically larger raw stats.

Use:

  • Titan aura;
  • full Growth;
  • Prime;
  • Talents;
  • Mutations;
  • genes;
  • equipment sets;
  • higher-tier species/hybrids;
  • facilities;
  • skill Mastery;
  • Expedition Ascension.

40. If you are stuck on a stage #

Use this checklist in order.

1. Check active party #

Are all three active slots filled?

2. Check Pack Power #

Compare your Pack Power against enemy threat.

3. Check Growth #

Are your main dinosaurs far behind their current Growth potential?

4. Spend Talent Points #

Unused points provide no benefit.

5. Check equipment slots #

Does every dinosaur have Weapon + Armour + Relic?

6. Upgrade equipment #

Level 1 gear can often be made substantially better cheaply.

7. Use Auto Equip #

Then inspect manually.

8. Check set bonuses #

Do not accidentally break a good 2/3-piece set.

9. Consider mutations #

A good permanent mutation can be a major jump.

10. Awaken Prime #

At 75% Growth if you have Essence.

11. Improve team synergy #

A Tank + attacker or Support + Tank/Brawler can outperform three random high-stat dinosaurs.

12. Farm a better Guardian / Mutant #

Gear is often the bottleneck.

13. Fight Titans #

Unique Titan kills add permanent Attack aura.

14. Use Training Grounds #

Compare packs without spending anything.

41. Common mistakes #

Using only one strong dinosaur #

Pack systems reward having a proper team.

Ignoring reserve dinosaurs #

Reserves can run Sanctuary Missions while your main pack fights.

Farming normal enemies for gear #

Normal enemies only have a 24% gear chance. Cleared Guardians are more reliable.

Expecting sweeps to farm Shards #

Sweeps do not award repeat boss Mutation Shards. Manually replay bosses when Shards are the goal.

Breaking a full equipment set #

Use the comparison warning before replacing a piece.

Salvaging good gear accidentally #

Use gear locks.

Spending every Shard early #

Mutations are permanent and hybrids need Shards later.

Forgetting free Stamina recovery #

Use Daily Rest before paying for a tonic if appropriate.

Leaving gathering capped #

Gathering stops accumulating after 8 hours until collected.

Assuming breeding requires the same species #

Parents only need the same diet. Offspring is one of the two parent species.

Expecting breeding to make hybrids #

It cannot. Hybrids require Mutant DNA and the Genetic Lab.

Sending battle-party dinosaurs on missions #

Sanctuary Missions use reserve companions.

Forgetting Weekly reset #

Weekly rewards must be claimed before Monday 00:00 AEST (UTC+10).

Moving websites without a backup #

Export the JSON first.
